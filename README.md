# 虾蛄公司 TikTok 毛利计算技能

按虾蛄公司已确认的口径，计算 TikTok Shop 商品的每单利润、利润率和最低保本 ROI，支持菲律宾、马来西亚和泰国，适用于所有商品。

完整计算规则见 [SKILL.md](SKILL.md)，技能名称为 `xiagu-tiktok-profit`。

## 使用示例

在安装此技能后，可以向 Codex 输入：

> 使用 $xiagu-tiktok-profit 计算：泰国，售价159泰铢，成本8.6元，实际ROI 10，佣金0%，不参加秒杀。

技能会采用指定汇率，或查询最新可用汇率并记录来源与查询时间。

## 计算口径

- 平台扣费默认22%，不含联盟佣金与秒杀额外费。
- 参加秒杀时额外扣3.21%；损耗按售价折合人民币的2%计提。
- 商品成本以人民币填写；每单贴单费默认3.5元，单独扣除。
- 使用已剔除取消订单的实际ROI，不再分摊10%取消率。
- 数字四舍五入显示1位小数，计算保留完整精度。
- 最低ROI为利润等于0时的完整精度阈值；显示值经过舍入，判断保本应看完整精度或实际利润。

以上为公司默认参数，可按实际调整，不代表 TikTok 官方统一费率。普通表格保存的汇率是查询快照，不会持续自动联网更新。
